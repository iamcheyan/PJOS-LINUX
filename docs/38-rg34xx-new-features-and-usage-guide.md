## 二、详细特性与技术说明

### 1. 像素化封面 (Pixelate Covers)

- **设计背景**：
  掌机整体界面采用复古点阵像素风格（Fusion Pixel 字体、像素风格工具与图标）。传统高清或非点阵封面在低分辨率屏幕上缩放容易失真或与 UI 产生割裂感。开启像素化封面后，系统会将卡片封面实时点阵化，呈现锐利复古的像素质感。
- **高质量像素算法优化**：
  为避免普通像素化算法导致封面“糊成一片、无法辨认”的问题，我们引入了专门针对掌机画面的多阶增强点阵算法：
  1. **自适应对比度增强 (Unsharp Masking)**：在降采样前计算局部邻域梯度并强化边缘反差，保留原始封面的主角轮廓与标题文字。
  2. **局部均值降采样 (Area-Average Pooling)**：以 2×2 / 3×3 块为单位计算加权均值，避免单一近邻采样产生的噪点走样。
  3. **复古调色板量化与色彩微调**：将 RGB 动态范围映射到适合 GBA / Retro 液晶的色阶，既保证了点阵的粒状颗粒感，又确保封面主体清晰可辨。
- **使用方法**：
  1. 在 PocketShell 启动器主页面，按肩键 **L1 / R1**（或 **L2 / R2**）切换到 **设置 (Settings)** 页面。
  2. 找到 **像素化封面 (Pixelate Covers)** 选项。
  3. 按 **A 键** 即可在 **开启 (ON) / 关闭 (OFF)** 之间切换。
  4. 切换后，主页轮播卡片（Carousel）和游戏库内的所有封面将立即应用效果，设置自动持久化保存，下次开机依然生效。

### 2. 游戏内音频恢复与低延迟配置

- **问题根因**：
  RG34XX 搭载全志 H700 芯片，在 Linux KMS 直驱模式下，RetroArch 之前的默认音频驱动回退机制未能正确接入 Linux ALSA 硬件混音设备（`hw:0,0`），导致进入 GBA 游戏后完全静音。
- **解决方案与调优**：
  - 更新 `overlay/usr/share/pocketshell/System/compat/share/retroarch/driver.cfg`：
    - 显式指定 `audio_driver = "sdl2"`，确保与 BaseOS 底层 SDL2 框架兼容。
    - 启用 `audio_sync = "true"`，保证音频时钟与视频垂直同步无缝对齐。
    - 设置合适的音频重采样器与缓冲区大小，消除爆音、杂音与延迟卡顿。
  - 实机测试表明音频与视频完美同步，保持稳定 60 FPS 满速运行。

### 3. 音量调节与长按快速静音

- **音量控制**：
  - 掌机物理音量按键与滚轮事件现已完全贯穿启动器与游戏内部。
  - 调节音量时，屏幕边缘会弹出绿色复古 OSD 音量指示条，直观显示当前电平（0% - 100%）。
- **快速静音模式 (Fast Mute)**：
  - 在公共场合或需要立即静音时，无需连续按音量减键。
  - **操作**：按住音量减键（或音量滚轮向左保持）约 1 秒，系统立即切入静音状态（音量归 0），OSD 提示出现静音状态。
  - 再次轻按一次音量加键即可恢复到之前的正常播放音量。

### 4. 8 种复古视觉滤镜引擎 (Retro Visual Filter)

- **高性能自研渲染引擎**：
  - 内嵌于 RetroBilingual 扩展核心（`core/retrobilingual.c`），采用极致优化的纯 CPU 渲染着色器。
  - 每帧渲染耗时仅 **0.23ms**（理论支持 4,300+ FPS），无 GPU/Shader 负载，不增加掌机功耗与发热。
  - 将 GBA 原生 240×160 精确 3× 放大至屏幕物理 720×480，并彻底关闭了 RetroArch SDL2 的双线性模糊滤波（`video_smooth = "false"`），确保 1:1 点对点刀锋般锐利。
- **8 种预设效果一览**：
  1. `0: OFF (RAW 3X)`：纯净原始图像，无任何滤镜效果。
  2. `1: LCD GRID`：3×3 经典液晶像素网格（75% 暗色边界与 50% 交叉点黑网格），还原掌机液晶屏质感。
  3. `2: GBA COLOR`：经典 AGB-001 原版 GBA 屏幕色彩校正矩阵（补偿现代高色彩液晶过饱和问题，重现卡带原版温润的调色风格）。
  4. `3: LCD + COLOR`（⭐ **官方推荐默认**）：结合 AGB-001 色彩还原与 LCD 液晶网格，最具沉浸感的实机视觉体验。
  5. `4: CRT SCANLINE`：横向扫描线效果，重现复古彩电与街机框体显示效果。
  6. `5: SUBPIXEL RGB`：模拟垂直红绿蓝（RGB）液晶子像素条纹。
  7. `6: GB DMG`：1989 年初代 Game Boy (DMG-01) 标志性四阶豌豆绿点阵液晶。
  8. `7: GB POCKET`：Game Boy Pocket / Light 高反差黑白灰度点阵液晶。
- **游戏内操作与切换**：
  1. 在游戏中随时按下掌机 **实体 Y 键**（机身左侧按键，PCB 映射 js 2），呼出 RetroBilingual 快捷菜单。
  2. 通过十字键 **上 / 下** 导航至第 5 项：`FILTER: < PRESET >`。
  3. 按 **左 (Left) / 右 (Right)** 键实时切换预设，游戏画面即时无缝刷新，屏幕底部会弹出绿色 Toast 浮动提示（例如 `FILTER: LCD + COLOR`）。
  4. 选好满意的滤镜后，按 **B 键** 或再次按下 **Y 键** 关闭菜单即可继续游玩。
  5. 滤镜选择会自动持久化保存到 `/storage/.config/pocketjs/retrobilingual.conf`（`visual_filter=X`），下次启动任何游戏自动载入所选偏好。
