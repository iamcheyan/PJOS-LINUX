## 二、 你的具体工作流程（Step-by-Step）

### 步骤 1：检查工作环境与现状

在工作区根目录执行以下命令，确认数据文件存在：

```bash
ls -lh data/glyph_mapping.json data/glyphs/index.json
python3 tools/chinese_text_recovery/decode_chinese_text.py
```

* 预期输出：目前已加载 195 个字形映射，剩余约 1,099 个未映射汉字待补充。

---

### 步骤 2：识别与填充汉字映射（核心任务）

你的核心任务是逐步往 `data/glyph_mapping.json` 中填充 `Tag -> 汉字` 的映射关系。

#### 格式规范：
```json
{
  "G1:21": "!",
  "G3:01": "[A]",
  "G4:01": "明",
  "G5:01": "量",
  "G6:01": "来",
  "G7:01": "斯"
}
```

#### 高效恢复策略（推荐结合以下两种方法）：

##### 方法 A：利用上下文对话模式反推（最快、最准）
运行解码脚本生成的 `data/chinese_utf8.json`，寻找游戏中显而易见的高频句子或主线剧情。例如：
- 看到 `塞尔[G4:xx]` $\to$ 必为“达”（塞尔达）。
- 看到 `林[G4:xx]` $\to$ 必为“克”（林克）。
- 看到 `缩小[G4:xx]` $\to$ 必为“帽”（缩小帽）。
- 看到 `[G5:xx]咕鸡` $\to$ 必为“咕”（咕咕鸡）。
- 看到 `海拉[G6:xx]` $\to$ 必为“鲁”（海拉鲁）。
- 看到 `皮克[G4:xx]` $\to$ 必为“罗”（皮克罗）。

只要确定一个汉字，即可在 `data/glyph_mapping.json` 中添加一行，整篇游戏中包含该字的所有对话将瞬间全部恢复！

##### 方法 B：查看字形位图或 ASCII 点阵
字模都是非常标准的 16×16 点阵。如果你想看某个字模长什么样，可以使用如下 Python 单行命令在终端中打印其清晰的 ASCII 点阵：

```bash
python3 -c "
from PIL import Image
img = Image.open('data/glyphs/G4_01.png')
for y in range(img.height):
    print(''.join('#' if img.getpixel((x, y))[3] > 0 else ' ' for x in range(img.width)))
"
```
终端会直接打印出汉字的骨架笔画，肉眼或模型一眼就能辨识。

## 三、 常用排错与注意事项

1. **严禁臆测乱猜**：
   遇到真正看不清的极生僻字，宁可留空让其保持 `[G4:xx]` 标记，也不要随便填一个不相关的字，以免污染游戏语意。
2. **标点与西文字符**：
   Bank 1 的 0x00..0x7F 为标准 ASCII，不要覆盖为汉字。
3. **保留控制符语义**：
   换行符 `\n`、分页等待 `[WAIT]`、玩家名称 `{player}` 均为游戏关键标记，解码工具已自动处理，切勿手动删除。
